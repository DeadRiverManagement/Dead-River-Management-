# parcelmanagementgroup.com

Static site built with [Astro](https://astro.build), hosted on Vercel. Maintained by
Dead River Management. Content and SEO updates are applied monthly by the automated
SEO run in the `seo-team` repo; humans can edit anything here too.

## Layout

```
src/pages/index.astro        Homepage. SEO fields (title, description, schema) in the `seo` block at the top.
src/pages/blog/index.astro   Blog listing (auto-generated from posts).
src/pages/blog/[slug].astro  Blog post template (Article + FAQPage + Breadcrumb schema).
src/content/blog/*.md        One markdown file per post. Frontmatter is the contract (see content.config.ts).
src/data/site.json           Business NAP, logo, phone. Feeds Organization schema.
src/data/faq.json            Homepage FAQ. Also emitted as FAQPage schema.
src/layouts/Base.astro       <head>, meta tags, JSON-LD, header/footer.
src/styles/site.css          Original redesign styles. blog.css = blog additions.
public/images/blog/          Hero images (generated by the monthly run).
public/site.js               Nav, FAQ accordion, reveal animations.
```

## Adding a blog post by hand

Create `src/content/blog/my-post.md`:

```md
---
title: "Under 70 characters"
description: "Under 170 characters."
pubDate: 2026-10-01
heroImage: /images/blog/my-post.webp
heroAlt: "What the image shows"
keyword: "primary keyword"
keywords: ["secondary", "queries"]
category: "Small Package"
faq:
  - q: "Question?"
    a: "Answer."
---
Body in markdown. Use question-form H2s; the first paragraph under each H2 is styled as the answer capsule.
```

Set `draft: true` to keep a post out of the build.

## Local dev

```
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
```
