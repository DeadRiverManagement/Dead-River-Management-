# Playbook image prompts

Paste each prompt into ChatGPT. Save the result with the file name given, then send me the files. I'll place them.

Style rules to paste at the top of every prompt:

> Style: clean editorial illustration for a printed business playbook. Warm off-white background (#f4f1ea). Line work in near-black (#121214). One accent color only: copper (#c8743f) with a lighter copper (#e3a070). No green, no blue, no gradients, no text or lettering in the image, no logos, no watermark. Simple, confident, slightly hand-drawn ink style with flat fills. Plenty of empty space around the subject.
