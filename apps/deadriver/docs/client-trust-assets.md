# Homepage client trust section

A static responsive row of six client logos appears directly below the homepage hero. Every logo links to its corresponding `/work/` case study. There is no conveyor motion, duplicate logo group, edge mask, pause control, or component JavaScript.

The six clients are Total Auto Repair, Gonzalez and Sons Roofing, The Pipe Whisperers, Parcel Management Group, Wicked Logistics, and Only Fish. Wicked Logistics now uses `public/images/clients/wicked-logistics-transparent.webp`, a transparent cutout of the existing teal/green truck-and-arrow mark. The old black-background file is retained but is no longer referenced by the current homepage or case studies. The other five assets are unchanged.

The grid uses six columns on desktop, three on tablet, and two on phones. Images have explicit dimensions, descriptive alt text, lazy loading, and async decoding. Links have a visible keyboard focus outline. Wicked Logistics and Only Fish use normal blending to preserve their colors.

The PMG result section, DemandFlow pages, VSL media, tracking, pricing, and forms are unchanged. Existing regression checks cover the static component and committed asset checksums.
